# Tamagotchi Paradise Sprite Catalog - Standalone Browser

This is a fully self-contained sprite browser with all necessary files included.

## Contents

- `sprite_catalog.html` - Main browser interface (683KB)
- `catalog.json` - Sprite metadata (314KB)
- `images/` - All 1,448 sprite images (7MB)

## Usage

Simply open `sprite_catalog.html` in any web browser. No server required!

The browser includes:
- Interactive grid view of all 1,449 sprites
- Search functionality by ID or description
- Sprite details (dimensions, subimages, palettes)
- Lazy loading for performance

## Features

- **Total Sprites:** 1,449
- **Exported:** 1,448
- **Skipped:** 1
- **Source:** Firmware dump extraction
- **All images:** Stored in relative `./images` folder

All paths are now relative - you can move this folder anywhere and it will work!
